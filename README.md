# دفتر حساب (PWA)

## محتوای فولدر
```
index.html          ← کل اپلیکیشن (HTML+CSS+JS در یک فایل)
manifest.json        ← مشخصات PWA (اسم، آیکون، رنگ)
sw.js                 ← service worker برای کارکرد آفلاین
icons/icon-192.png
icons/icon-512.png
icons/apple-touch-icon.png
```

## روش آپلود در GitHub Pages

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلاً `hesabdari`).
2. تمام فایل‌ها و پوشه‌ی `icons` را داخل ریشه‌ی همان ریپازیتوری آپلود کنید
   (از دکمه‌ی *Add file → Upload files* در گیت‌هاب یا با `git push`).
   **نکته مهم:** ساختار فولدر باید همین‌طور که هست حفظ شود — یعنی
   `manifest.json`، `sw.js` و پوشه‌ی `icons` باید هم‌سطح `index.html`
   باشند، نه داخل یک زیرپوشه‌ی دیگر.
3. به `Settings → Pages` بروید، در بخش *Source* شاخه (branch) و مسیر
   `/ (root)` را انتخاب کنید و ذخیره کنید.
4. بعد از چند دقیقه، آدرسی شبیه این فعال می‌شود:
   `https://USERNAME.github.io/REPO-NAME/`
5. همین آدرس را در Safari آیفون باز کنید → دکمه‌ی Share → **Add to Home
   Screen**. از این به بعد مثل یک اپ مستقل روی گوشی نصب و اجرا می‌شود.

## نکات مهم

- **داده‌ها فقط روی خودِ گوشی ذخیره می‌شوند** (در حافظه‌ی مرورگر همان
  دستگاه)؛ چیزی به سرور گیت‌هاب یا هیچ سرویس دیگری ارسال نمی‌شود.
- اگر بعداً محتوای `index.html` را عوض کردید و در گیت‌هاب آپدیت کردید،
  حتماً عدد نسخه در خط اول فایل `sw.js` (`CACHE_NAME`) را تغییر بدهید
  (مثلاً از `v4` به `v5`)، وگرنه ممکن است کاربرها همچنان نسخه‌ی کش‌شده‌ی
  قدیمی را ببینند.
- **افزودن چک به تقویم اپل، دو ضربه لازم دارد** (نه یک ضربه‌ی جادویی):
  1) روی «افزودن به تقویم» می‌زنید → فایل رویداد دانلود می‌شود.
  2) از نوار دانلود بالای سافاری، یا از اپ **Files**، یک بار روی همان
     فایل ضربه می‌زنید (نه دکمه‌ی Share) → صفحه‌ی بومی «Add to Calendar»ی
     خودِ آیفون باز می‌شود و رویداد را اضافه می‌کنید.
  این محدودیتِ خودِ iOS/Safari است: هیچ وب‌اپی (چه PWA باشد چه نه) روی
  آیفون نمی‌تواند بدون این یک ضربه‌ی اضافه، مستقیماً به تقویم بنویسد؛
  در دکمه‌ی Share معمولی هم Calendar هیچ‌وقت به‌عنوان مقصد ظاهر نمی‌شود.
